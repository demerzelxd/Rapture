There is a specific pleasure in building a place that does not need to explain itself.

Rapture starts as a surface: ink, brass, cyan light, a private city below the easy web. The writing can stay small for now. The doorway is the point.

I want the page to feel less like a profile and more like a pressure door opening.

```ts
const oath = ['writing', 'photography', 'a city below the surface'];
```

The site can grow later. First, it has to be worth entering.
